PROJECTS

KisaanKar

KisaanKar is a vehicular robot aimed at empowering farmers by integrating automation into agriculture. Designed to address challenges like water scarcity and inefficient resource use, it utilizes sensors to optimize irrigation, monitor soil health, and improve crop yields.

Facial Tracking

Utilizes Python's OpenCV library to track facial coordinates in real time using a webcam. The system interfaces with an Arduino, which processes the detected coordinates and maps them onto servo motors, allowing a mounted camera to follow the user's face.

Prosthetic Hand

Using OpenCV and a webcam, this project tracks hand movements and maps them onto a 3D-printed prosthetic hand via Arduino-controlled servos. Each finger’s motion is mirrored in real time using coordinates which are then parsed to map onto servos.
